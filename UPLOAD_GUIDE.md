# ECHO//TRACE & echotrace-math — Upload & Submission Guide

This guide details the **6 ZIP Tiers** generated by `scripts/make-zips.ps1` for the **Embarko Student Challenge** and GitHub release distributions.

---

## The Six Submission Tiers

| ZIP Archive | Distribution | Tier | Contents | Target Use Case |
| :--- | :--- | :---: | :--- | :--- |
| `echotrace-site-tierS.zip` | Site (App) | **S** | Static `dist/` production assets only | Immediate static deployment to Embarko, Cloudflare Pages, Netlify, or AWS S3 when upload limits are strict (< 5 MB). |
| `echotrace-site-tierM.zip` | Site (App) | **M** | Clean app source, configs, tests (`dist-a-site`) | Code review submissions where reviewers will run `npm install && npm run build`. Excludes `node_modules`, `.git`, and media. |
| `echotrace-site-tierL.zip` | Site (App) | **L** | Full repo-ready site with all configs & tests | Full challenge submission archive when portal allows up to 25 MB. |
| `echotrace-lib-tierS.zip` | Library | **S** | Single-file minified bundle (`.min.js`) + `.d.ts` | Zero-dependency drop-in for Web Workers, browser `<script>`, or CDN distribution (< 30 kB gzip). |
| `echotrace-lib-tierM.zip` | Library | **M** | Pure TypeScript source (`src/`) + manifests | Direct `npm publish` or submodule vendoring in another project. |
| `echotrace-lib-tierL.zip` | Library | **L** | Standalone repo with `docs/MATH.md`, benchmarks, tests | Pitching `echotrace-math` on GitHub as a standalone open-source scientific tool. |

---

## Which ZIP Should You Upload?

### 1. Embarko Student Challenge Submission Portal
- **If the portal asks for a pre-built static site bundle:**  
  Use `release-zips/echotrace-site-tierS.zip`. Unzips directly into production HTML, CSS, JS, and local fonts. Requires zero backend server.
- **If the portal asks for full source code for judging:**  
  Use `release-zips/echotrace-site-tierM.zip`. It contains 100% of the TypeScript source code, unit tests, and configs, cleanly stripped of `node_modules` and heavy binaries.

### 2. Standalone GitHub Repository Pitch (`echotrace-math`)
- Use `release-zips/echotrace-lib-tierL.zip` as the initial repository commit or attach `echotrace-lib-tierS.zip` to GitHub Releases.
- Includes:
  - Complete zero-dependency TypeScript implementation (`src/`).
  - Comprehensive mathematical proof document (`docs/MATH.md`).
  - Test suites and real benchmark verification scripts.
  - Apache 2.0 License, NOTICE, and `CITATION.cff`.

## How to Re-generate All Tiers

Run the automated PowerShell packaging engine from the repository root:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/make-zips.ps1
```

This single command:
1. Re-syncs `/dist-a-site` and `/dist-b-library`.
2. Compiles TypeScript declarations and builds the single-file minified library bundle (`echotrace-math.min.js`).
3. Compiles the production site distribution.
4. Generates all 6 optimal ZIP archives in `/release-zips`.
5. Prints the exact size table to the terminal.

### Strict Cleanliness Guarantees
Every generated ZIP strictly excludes:
- `node_modules`
- `.git`
- `screenshots/` (strictly prohibited)
- `test-media/` audio and video files ($> 5\text{ MB}$)
- Temporary build caches (`*.tsbuildinfo`, `.DS_Store`)
